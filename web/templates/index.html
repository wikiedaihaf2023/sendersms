📱 طريقة عمل بوابة الهاتف (Sapa GSM / SMS Gateway Pro):
1. ثبّت تطبيق (Sapa GSM / SMS Gateway Pro / Sapa Phone Gateway) على هاتف الأندرويد الذي به شريحة يمن موبايل. 2. فعّل خيار Local HTTP Server أو Web Server داخل التطبيق. 3. ضع المنفذ (Port) عادةً 8080 أو 8090 وحرر إعدادات الحماية على الهاتف. 4. انسخ عنوان IP للهاتف من نفس الشبكة مثلاً: http://192.168.1.15
اختر التطبيق المستخدم على الهاتف وسنتولى الباقي.
أدخل IP الهاتف فقط - سيتم بناء الرابط الكامل تلقائياً بناءً على الـ Preset.
اربط الهاتف من واتساب ويب أو افتح محادثة مباشرة. لا يتم تشغيل إرسال آلي من حسابك الشخصي.
